Zadanie JavaScript: zdarzenia

Temat: click, input, change, submit

Treść zadania

  • Dodaj obsługę zdarzenia click, która zmienia wygląd komunikatu po kliknięciu przycisku.
  • Użyj zdarzenia input, aby na bieżąco wyświetlać tekst wpisywany w pole oraz liczbę znaków.
  • Obsłuż change na liście wyboru i pokaż wybraną opcję po zmianie wartości.
  • Obsłuż submit formularza: zatrzymaj domyślne odświeżenie strony metodą preventDefault() i wyświetl powitanie.
  • Przetestuj wszystkie cztery zdarzenia i opisz, kiedy każde z nich się uruchamia.

Przykład działania

Kliknij przycisk, aby wyróżnić ten komunikat.

Podgląd: — (0 znaków)

Nie wybrano jeszcze tematu.

Kod HTML

<p id="message">Kliknij, aby wyróżnić komunikat.</p>
<button id="highlightButton" type="button">Wyróżnij</button>

<label for="nameInput">Wpisz tekst</label>
<input id="nameInput" type="text">
<p>Wpisano: <span id="typedText">—</span></p>

<label for="topicSelect">Wybierz temat</label>
<select id="topicSelect">
  <option value="">-- wybierz --</option>
  <option value="click">click</option>
  <option value="input">input</option>
</select>

<form id="greetingForm">
  <input id="formName" type="text" required>
  <button type="submit">Wyślij</button>
</form>
<p id="formMessage"></p>

Kod JavaScript

const message = document.querySelector("#message");
const nameInput = document.querySelector("#nameInput");
const topicSelect = document.querySelector("#topicSelect");
const greetingForm = document.querySelector("#greetingForm");

// click: reaguje na kliknięcie przycisku
document.querySelector("#highlightButton").addEventListener("click", () => {
  message.classList.toggle("highlight");
});

// input: reaguje na każdą zmianę tekstu podczas pisania
nameInput.addEventListener("input", (event) => {
  const text = event.target.value;
  document.querySelector("#typedText").textContent = text || "—";
  document.querySelector("#charCount").textContent = text.length;
});

// change: reaguje, gdy wartość pola zostanie zmieniona
topicSelect.addEventListener("change", (event) => {
  const selected = event.target.value;
  document.querySelector("#selectionMessage").textContent =
    selected ? `Wybrany temat: ${selected}` : "Nie wybrano jeszcze tematu.";
});

// submit: reaguje na wysłanie formularza
greetingForm.addEventListener("submit", (event) => {
  event.preventDefault();
  const name = document.querySelector("#formName").value.trim();
  document.querySelector("#formMessage").textContent =
    `Cześć, ${name}! Formularz został obsłużony.`;
});
