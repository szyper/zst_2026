Zmiana elementów HTML za pomocą JavaScript

Kliknij przyciski i obserwuj, jak JavaScript zmienia treść, atrybuty oraz style elementów

To jest przykładowa treść, którą można zmienić

Jak to działa?

  • document.getElementById() wyszukuje element po jego identyfikatorze
  • TextContent zmienia tekst elementu
  • setAttribute() ustawia atrybut, na przykład title albo src
  • classList.toggle() włącza lub wyłącza klasę CSS, która zmienia wygląd
  • addEventListener() reaguje na kliknięcie przycisku
